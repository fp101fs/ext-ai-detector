# AI Detector — Chrome Extension

A Chrome browser extension that scans the current tab for AI-written text and shows the percentage of content likely generated by AI, with real-time streaming results.

![Chrome Extension](https://img.shields.io/badge/Chrome-Extension-blue?logo=googlechrome)
![License](https://img.shields.io/badge/License-MIT-green)

## Features

- **Scans all paragraphs** on the current tab for AI-generated content
- **Overall AI percentage** displayed in the extension popup with an animated score circle
- **Per-paragraph breakdown** with individual AI probability scores — updates in real time as each paragraph is scanned
- **Color-coded highlighting** on the page — red outlines for AI-like paragraphs, green for human-like, with percentage badges
- **Real-time streaming** — results appear paragraph-by-paragraph without waiting for the full scan
- **Stop button** — cancels an in-progress scan and resets the UI
- **Reset button** — clears all results and page highlights
- **Auto-scan on navigation** — automatically scans the new page when you navigate to a different URL
- **Configurable model ID** — text input with default `openai/gpt-oss-20b` and fallback `openai/gpt-oss-20b`
- **Batch processing** — scans multiple paragraphs in parallel for faster results
- **Three detection modes**: OpenRouter, Heuristic, Hybrid
- **Progress bar** — shows scan stages (scanning → extracting → analyzing → complete)
- **Responsive, accessible UI** — follows [make-interfaces-feel-better](https://github.com/jakubkrehel/make-interfaces-feel-better) design principles

## Detection Modes

| Mode | Description | Requires API Key? |
|------|-------------|-------------------|
| **OpenRouter** | Sends text to OpenRouter API for classification | Yes |
| **Heuristic** | Offline analysis using sentence uniformity, vocabulary richness, AI phrase patterns, repetition, and hedging | No |
| **Hybrid** | Blends OpenRouter (70%) + heuristic (30%) for best accuracy | Yes |

## Setup

1. **Install the extension**:
   - Open Chrome → `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked" → select the extension folder

2. **Enter your OpenRouter API key** (optional — heuristic mode works without one):
   - Click the extension icon
   - Paste your OpenRouter API key (format: `sk-or-v1-...`)
   - Click "Save"
   - Get a free API key at [https://openrouter.ai/keys](https://openrouter.ai/keys)

3. **Scan any page**:
   - Navigate to any webpage
   - Click the extension icon
   - Click "Scan This Page"
   - Results show the overall AI probability and per-paragraph details

4. **Auto-scan**: Toggle "Auto-scan on navigate" in the popup to automatically scan pages as you navigate.

## How It Works

### OpenRouter Detection
Sends each paragraph (truncated to 1000 chars) to the OpenRouter API with a system prompt asking for a JSON `ai_probability` score between 0 and 1. Uses the configurable model (default `openai/gpt-oss-20b`).

### Heuristic Detection
Runs entirely in the browser — no API calls needed. Analyzes 5 signals:
1. **Sentence length uniformity** — AI tends to write with consistent sentence lengths (low coefficient of variation)
2. **Vocabulary richness** — AI typically uses a narrower vocabulary (lower type-token ratio)
3. **AI phrase patterns** — Detects 40+ common AI transition phrases and filler words
4. **Sentence starter repetition** — AI often repeats sentence opening patterns
5. **Hedging word density** — AI uses more qualifiers (may, might, could, potentially, etc.)

Each signal is scored 0–1 and combined with weighted averaging to produce a final probability.

### Hybrid Detection
Combines OpenRouter (70% weight) + heuristic (30% weight) for improved accuracy. Falls back to heuristic if the API call fails.

## UI Design Principles

The interface follows the [make-interfaces-feel-better](https://github.com/jakubkrehel/make-interfaces-feel-better) methodology:
- **Typography**: Clear hierarchy with uppercase labels, proper line height, and system font stack
- **Colors**: Dark theme with semantic color roles (purple accent, green/red for AI/human)
- **Spacing**: Consistent 4px/8px/12px/16px/24px/32px scale
- **Shadows**: Subtle elevation with consistent shadow intensity
- **Animations**: 150–300ms transitions with ease-out curves, respects `prefers-reduced-motion`
- **Hit areas**: Minimum 44×44px click targets for accessibility
- **Border radius**: Concentric radius (larger elements = larger radius)
- **Hover states**: Visible and immediate feedback on all interactive elements
- **Tabular numbers**: Aligned digits in score displays
- **Font smoothing**: Antialiased text rendering
